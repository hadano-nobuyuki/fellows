# 作業指示書(VBA)　Freeライセンス用

Claude に渡す作業指示書です。

`指示書.xlsx` と同じ内容を Markdown にしたものです。「補足」は引用(>)で示します。


## 指示内容１ 作業フォルダに関する情報

- チャットに以下のファイルを添付する
  - login.html、product_list.html、order_detail.html、テーブル定義書（myappdb）.sql
- 添付時にファイル名に「_1」などが付いても同じファイルとして扱う

> **補足**  
> html は画面の項目・並び・表示形式の参考として使う(Excel で html は表示しない)。  
> style.css と logo.svg は VBA では使わないので添付しなくてよい  

- チャットでは .xlsm ファイルを直接作れないため、VBA のコードをファイルに分けて出力し、zip にまとめる
- zip の直下に次のファイルを置く
  - modDb.bas、modMain.bas、modSetup.bas、ThisWorkbook.txt、Sheet_ログイン.txt、Sheet_商品一覧.txt、組込手順.txt
- 各ファイルは Shift_JIS(CP932)、改行 CRLF で保存する(UTF-8 だと VBE に取り込んだときに日本語が文字化けする)
- .bas の1行目は Attribute VB_Name = "モジュール名" とする

> **補足**  
> 講義では受講生に実施させない。講師が自分のアカウントで生成し、コードを組み込んだ Sample01.xlsm を作って素材として渡す  


## 指示内容２ 生成物の条件定義

### (1)以下の内容でExcel VBAのアプリを生成すること
- Excel(Microsoft 365、64bit)のマクロ有効ブックに組み込む VBA コード
  - 組み込み先のブック名："Sample01.xlsm"
  - DB 接続：ADO + psqlODBC(ドライバ名 "PostgreSQL Unicode(x64)")
  - `DBMS:PostgreSQL 18.4`

> **補足**  
> psqlODBC は Excel と同じ 64bit 版を事前にインストールしておく  

### (2)生成物の構成
- 標準モジュールは modDb(DB 接続と SQL 実行。設定シートの読み込みを含む)、modMain(ログイン状態の管理、各シートの表示、ログアウト)、modSetup(シートと画面部品の作成)の3つに分ける
- modSetup の BuildWorkbook は、空のブックで1回実行するとブックが完成するようにする。次をすべて行う
  - シート「ログイン」「商品一覧」「注文情報詳細」「設定」の作成と見出しの入力
  - 名前付き範囲 LoginMessage、ActiveX の txtUserName・txtPassword・cmdLogin、ボタン(図形)の作成
  - 「設定」シートの A 列の項目名の入力
- ユーザーフォームは使わない。ログインは「ログイン」シートで行う
- ADO は CreateObject("ADODB.Connection") などの遅延バインディングで使う(参照設定は不要にする)
- すべてのモジュールに Option Explicit を付ける
- エラー時はメッセージを表示し、接続を必ず閉じる
- ThisWorkbook.txt には Workbook_Open を書く。初期化処理でエラーが起きた場合は、メッセージにプロシージャ名とエラー番号も表示する
- シートのイベント処理は Sheet_ログイン.txt(ログイン画面の KeyDown など)と Sheet_商品一覧.txt(Worksheet_FollowHyperlink)に書く
- ThisWorkbook.txt と Sheet_*.txt は、VBE の該当モジュールにコピーして貼り付けられる形にする
- ThisWorkbook やシートのコードから標準モジュールの処理を呼ぶときは、modMain.InitWorkbook のようにモジュール名で修飾して呼ぶ
- 参照設定に無いライブラリの定数(ADO の adVarWChar・adParamInput など、MSForms の fm～ など)はそのまま使わず、モジュールの先頭で Const として値を宣言して使う
- チャットでは VBE のコンパイルができないので、出力前にコード全体を見直し、宣言されていない定数・変数、モジュール名の誤り、構文エラーが無いことを確認する

> **補足**  
> 講師が Claude Code で生成に成功した「VBA生成.xlsm」と同じ方式(シート上のログイン画面)  
> Option Explicit のため、宣言されていない定数があると「変数が定義されていません」のコンパイルエラーになる  
> .bas をインポートするとモジュール名は Attribute VB_Name の値になる  

### (3)ブックの構成
- シート：「ログイン」「商品一覧」「注文情報詳細」「設定」
- ログイン中のユーザーは modMain の Public 変数 gLoginUser(eメール)で管理する

### (4)DBの接続情報は「設定」シートから読み込むこと(コードに値を直書きしない)
- 「設定」シートの A 列に項目名、B 列に値を置く
  - `DB_HOST=localhost`
  - `DB_PORT=5432`
  - `DB_NAME=myappdb`
  - `DB_USER=myapp`
  - `DB_PASSWORD=1234`

> **補足**  
> パスワードがブックに保存されるため、ブックを他人に渡すときは B 列の値を消す  

### (5)テーブル定義と初期データは以下の SQL ファイルを参照
- テーブル定義書（myappdb）.sql
- DDL(CREATE TABLE)と初期データ(INSERT)が書かれている。テーブル名・列名・型・主キーはこのファイルのとおりにする
- VBA からはテーブルの作成・データ投入・削除(DDL/DML)を実行しない。データの読み取り(SELECT)だけを行う
- [廃番商品]テーブルは本アプリでは使わない
- テーブル名・列名は日本語のまま SQL に書く
- SQL の値は ADODB.Command のパラメータ(?)で渡し、文字列連結しない

> **補足**  
> このSQLは各テーブルを DROP TABLE … CASCADE で削除して作り直す。実行するとデータが初期化されるため、研修用DB(myappdb)以外では実行しない。  
> アプリを動かす前に、DB で実行してテーブルと初期データを作っておく(A5M2 など)  


## 指示内容3 ログイン画面

### (1)「ログイン」シートを生成し、ブックを開いたとき(Workbook_Open)にこのシートを表示すること
- 項目と文言は以下に準拠
  - `login.html`
- タイトル「ログイン画面」、ユーザ名入力欄、パスワード入力欄、ログインボタン、メッセージセル(名前付き範囲 LoginMessage)を置く
- ユーザ名とパスワードの入力欄は、どちらもセルではなく ActiveX のテキストボックスにする(txtUserName、txtPassword)。txtPassword は PasswordChar="●"
- 2つのテキストボックスは同じ大きさ・枠線・背景色・フォントにそろえ、見た目を同じにする
- txtUserName、txtPassword とログインボタン(cmdLogin)は、modSetup の BuildWorkbook で作成する
- シート上の ActiveX コントロールは Tab キーで自動的に移動しないため、KeyDown イベントで移動を実装する
  - txtUserName：Enter / Tab → txtPassword へ移動
  - txtPassword：Enter → ログイン実行、Tab → cmdLogin へ移動、Shift+Tab → txtUserName へ戻る
  - cmdLogin：Enter → ログイン実行、Shift+Tab → txtPassword へ戻る
- 移動は KeyCode = 0 にしたうえで、移動先の OLEObject を Activate して行う

> **補足**  
> セルは入力中の文字を伏字にできず、またメールアドレスを入力すると Excel が自動でハイパーリンクにし、クリックでメーラーが起動してしまうため、ユーザ名も ActiveX のテキストボックスにする。  
> ActiveX が組織の設定で無効になっている PC では表示されないので事前に確認する  

### (2)ログイン時の認証を組み込む

### (2-1)ログイン認証用アイテム
- ”ユーザ名”
  - ”パスワード”

### (2-2)ログイン時の認証方法
- [ユーザー情報]テーブルの値との一致を認証する
  - ”ユーザ名”：[ユーザー情報].eメール と値が一致すること
  - ”パスワード”：照合は DB 側で行う。以下の条件で件数が 1 件以上なら認証成功とする
  - WHERE eメール = ? AND パスワード = encode(sha256(convert_to(?, 'UTF8')), 'hex')
- VBA ではパスワードのハッシュ計算を行わない

> **補足**  
> Java・Python と同じ SHA-256(UTF-8、小文字16進64桁、ソルトなし)になるため、同じユーザーでログインできる(相互ログイン)  

### (2-3)ログイン認証に成功：
- gLoginUser に eメール を保存し、パスワード欄を空にして「商品一覧」シートを表示し一覧を読み込む

### (2-4)ログイン認証に失敗：
- パスワード欄を空にし、メッセージセル(LoginMessage)にメッセージを赤字で表示する

> **補足**  
> ログイン認証失敗時には以下のメッセージを表示(html に準拠)  
> 「ユーザ名またはパスワードが正しくありません。」  


## 指示内容４ 商品一覧シート

### (1)「商品一覧」シートの生成
- 項目・並び・表示形式は以下に準拠
  - `product_list.html`
- 1行目にタイトル「商品一覧画面」とログイン中のユーザー(gLoginUser)を表示する
- 3行目を見出し行(商品コード、商品名、単価、商品区分、関連商品コード、注文状況)とし、4行目以降にデータを出力する
- 「ログアウト」ボタン(図形)を置き、マクロを登録する
- ボタン(図形)は高さ 24pt 以上とし、文字は上下・左右とも中央に揃える(TextFrame2.VerticalAnchor = msoAnchorMiddle、TextFrame2.TextRange.ParagraphFormat.Alignment = msoAlignCenter、上下の余白は 0)

### (2)ログインしていない状態(gLoginUser が空)で一覧を表示しようとした場合：
- 「ログイン」シートを表示する

> **補足**  
> VBA のリセットやエラーで変数が消えた場合も、この判定でログイン画面に戻る  

### (3)ログアウトボタン
- gLoginUser を空にし、「商品一覧」「注文情報詳細」のデータ行を消してから「ログイン」シートを表示する

### (4)「商品一覧情報」の生成
- [商品テーブル]と[注文テーブル]を取り込む

### (4-1)[商品テーブル]は全件取り込む

### (4-2)[商品テーブル]は[注文テーブル]とLEFT JOINする(結合キー：”商品コード”）

### (5)「商品一覧」シートへの情報セット
- 出力前に 4行目以降の前回のデータを消す

### (5-1)(4)で生成した「商品一覧情報」から画面に表示する項目をすべてセットする
- ”商品コード”の昇順で表示
- ”注文状況”には、[注文テーブル]に情報が存在する商品について ”注文日”と”注文番号”の組の種類数を”件数”として「注文(n 件)」の形式で表示する
- 件数は次の式で数える(注文が無い商品は 0 件になる)
  - `COUNT(DISTINCT (o.注文日, o.注文番号)) FILTER (WHERE o.注文番号 IS NOT NULL)`
- 件数が 0 件の商品は「注文なし」と表示する
- 表示形式は html に準拠する(単価は #,##0、商品名は25文字まで)

> **補足**  
> 主キーに注文日が含まれ、別の日に同じ注文番号があり得るため、注文日と注文番号の組で数える。  
> LEFT JOIN で注文が無い商品は (NULL, NULL) の組になり、FILTER を付けないと 1 件と数えられてしまう  

### (5-2)”注文状況”のセルには「注文情報詳細」シートへのハイパーリンクを設定する
- リンクをクリックしたら(Worksheet_FollowHyperlink)、その行の”商品コード”の注文を「注文情報詳細」シートに表示する
- ”注文”情報が存在しない”商品”の”注文状況”は「注文なし」と表示しリンクは設定しない(html に準拠)
- ”関連商品コード”が無い場合は「―」と表示する(html に準拠)


## 指示内容５ 注文情報詳細シート

### (1)「注文情報詳細」シートの生成
- 項目・並び・表示形式は以下に準拠
  - `order_detail.html`
- 1行目にタイトル「注文情報詳細画面」、2行目に「商品コード:xxxxx」を表示する
- 4行目を見出し行(注文日、注文番号、注文枝番、数量、クーポン割引料)とし、5行目以降にデータを出力する
- 「ログアウト」ボタンと「← 商品一覧に戻る」ボタン(図形)を置き、マクロを登録する
- ボタン(図形)は高さ 24pt 以上とし、文字は上下・左右とも中央に揃える(TextFrame2.VerticalAnchor = msoAnchorMiddle、TextFrame2.TextRange.ParagraphFormat.Alignment = msoAlignCenter、上下の余白は 0)

### (2)ログインしていない状態で表示しようとした場合：
- 「ログイン」シートを表示する

### (3)「注文情報詳細」シートへの情報セット
- 出力前に 5行目以降の前回のデータを消す
- [注文テーブル]から、選択された”商品コード”に一致する注文を抽出して一覧表示する
- ”注文日”降順、”注文番号”降順、”注文枝番”昇順で表示する
- 表示形式は html に準拠する(注文日は yyyy/mm/dd で左寄せ、数量は #,##0、クーポン割引料は #,##0;[Red]-#,##0)
- 書式は NumberFormat プロパティに英語の書式コードで設定する([赤] などの日本語の色指定は使わない。日本語で書く場合は NumberFormatLocal を使う)
- クーポン割引料が NULL の場合は空欄にする
- 注文日の列は日付の値のまま HorizontalAlignment = xlLeft にする(Excel は日付を標準で右寄せにするため)

> **補足**  
> NumberFormat に [赤] を渡すと「Range クラスの NumberFormat プロパティを設定できません」(1004)になる  

### (4)ログアウトボタン
- 商品一覧シートと同じログアウト処理を行う

### (5)「← 商品一覧に戻る」ボタン
- 「商品一覧」シートを表示する
