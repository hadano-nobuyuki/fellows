============================================================
 Sample01.xlsm 組込手順(VBA 版)
============================================================

【事前準備】
  1. 64bit 版 Excel(Microsoft 365)と同じ 64bit 版の psqlODBC をインストールする
     (ODBC ドライバ名: PostgreSQL Unicode(x64))
  2. DB(研修用 myappdb)で「テーブル定義書(myappdb).sql」を実行し、
     テーブルと初期データを作っておく(A5M2 など)
     ※ このSQLは各テーブルを DROP して作り直す。研修用DB以外では実行しない
  3. ActiveX コントロールが組織の設定で無効になっていないことを確認する

【組込手順】
  1. 空のマクロ有効ブック(シートは1枚だけの新規ブック)を作り、
     「Sample01.xlsm」(Excel マクロ有効ブック)の名前で保存する
  2. Alt+F11 で VBE を開き、[ファイル]-[ファイルのインポート] で次の 3 つを取り込む
       modDb.bas / modMain.bas / modSetup.bas
     (モジュール名は 1 行目の Attribute VB_Name の値になる)
  3. VBE の「ThisWorkbook」を開き、コード画面を全選択して削除してから、
     ThisWorkbook.txt の内容をすべて貼り付ける
  4. modSetup の BuildWorkbook を実行する
       (modSetup を開き、BuildWorkbook の中にカーソルを置いて F5)
     → シート「ログイン」「商品一覧」「注文情報詳細」「設定」、
       名前付き範囲 LoginMessage、ActiveX(txtUserName / txtPassword / cmdLogin)、
       ボタン(図形)が作られる
  5. VBE で「ログイン」シートのコード画面を全選択して削除してから、
     Sheet_ログイン.txt の内容を貼り付ける
     同様に「商品一覧」シートに Sheet_商品一覧.txt の内容を貼り付ける
       ※ プロジェクト エクスプローラーで「Sheet1 (ログイン)」のように
         ( ) 内がシート名のものを選ぶ
  6. 「設定」シートの B 列に接続情報を入力する
       DB_HOST      localhost
       DB_PORT      5432
       DB_NAME      myappdb
       DB_USER      myapp
       DB_PASSWORD  1234
  7. 上書き保存(.xlsm)して、ブックを閉じてから開き直す
     (マクロを有効にする。デザイン モードは ON のままにしない)

【動作確認】
  1. ブックを開き直すと「ログイン」シートが表示される
  2. ユーザ名 user@example.com / パスワード 1234 でログインすると、
     「商品一覧」シートに一覧が表示される
     (Java または Python のアプリでも同じユーザーでログインできれば、相互ログインの確認も完了)
  3. 「注文状況」のリンクをクリックすると、「注文情報詳細」シートにその商品の注文が表示される
  4. 「← 商品一覧に戻る」で商品一覧に戻り、「ログアウト」でログイン画面に戻る
  5. 誤ったパスワードでは、赤字で
     「ユーザ名またはパスワードが正しくありません。」と表示される

【キー操作(ログイン画面)】
  ユーザ名:     Enter / Tab → パスワード
  パスワード:   Enter → ログイン、Tab → ログインボタン、Shift+Tab → ユーザ名
  ログインボタン: Enter → ログイン、Shift+Tab → パスワード

【うまく動かないとき】
  - ログイン画面の入力欄が反応しない
      → [開発] タブの「デザイン モード」が ON になっていないか確認する
  - 「データソース名が見つかりません」等の接続エラー
      → psqlODBC(64bit)のインストールとドライバ名、「設定」シートの値を確認する
  - 「ユーザ名またはパスワードが正しくありません。」が正しい入力でも出る
      → DB に初期データが入っているか(ユーザー情報テーブル)を確認する
  - 「変数が定義されていません」などのコンパイルエラー
      → モジュールを二重に取り込んでいないか、貼り付け前にコードを全削除したか確認する
  - ブックを他人に渡すときは、「設定」シートの B 列の値を消す(パスワードが保存されるため)
