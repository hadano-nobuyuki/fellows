# 講義用 環境構築ツール（fellows-phase1）

このリポジトリには、次の 2 つのフォルダが入っています。

- **①環境構築**: 講義で使う開発環境を、受講生の PC に準備するツール（このページの内容）
- **②講義用**: 講義の教材（指示書、画面 HTML、テーブル定義書など）

受講生が講義の前に使うのは、**①環境構築** フォルダだけです。

## 講義の前に、準備を終わらせてください

環境構築には 10〜20 分ほどかかります（インターネット接続が必要です）。
**講義が始まる前に、各自で済ませておいてください。** 講義の時間は、環境構築ではなく、講義の内容に使います。

## 準備するソフトと入手先

必要なソフトは、次の場所から入手します。ほとんどは、`setup.bat` が自動でダウンロードします。

| ソフト | 用途 | 入手先 |
|---|---|---|
| Pleiades All in One Eclipse | Java の開発 | このリポジトリの [Releases](../../releases) |
| PostgreSQL | データベース | このリポジトリの [Releases](../../releases) |
| psqlODBC | Excel などからデータベースに接続 | このリポジトリの [Releases](../../releases) |
| Python 3.12 | Python の開発 | このリポジトリの [Releases](../../releases)（公式サイト [python.org](https://www.python.org/downloads/windows/) でも入手できます） |
| Visual Studio Code | Python の開発 | [公式サイト](https://code.visualstudio.com/download)（`setup.bat` が自動で取得します） |

## 環境構築の手順

1. このページ右上の緑のボタン［Code］→［Download ZIP］で、ZIP をダウンロードします。
2. ZIP を **「右クリック → すべて展開」** で展開します。展開先は、`C:\fellows` のように、**半角英数字だけの短いフォルダ**にしてください。
3. 展開したフォルダの中の **①環境構築** フォルダを開き、その中の **setup.bat** をダブルクリックします。
   - 「Windows によって PC が保護されました」と出たら、［詳細情報］→［実行］を押します。
   - 「このアプリがデバイスに変更を加えることを許可しますか?」と出たら、［はい］を押します。
4. 黒い画面に進み具合が表示されます。**終わるまで閉じずに待ってください。**
   - 途中で「Pleiades All in One 自己解凍書庫」の画面が出たら、展開先は変えずに［解凍］を押します。
5. 最後に表示される「結果」を確認します。
   - 「インストール完了」「スキップ」「作成完了」…… 問題ありません。
   - 「失敗」…… そのまま講義で相談してください（下の「問題が発生した場合」を参照）。
6. 開いているコマンドプロンプトや VS Code は、いったん閉じます。

詳しい内容は、フォルダ内の「②一括セットアップの使い方.txt」を見てください。

### すでに PostgreSQL をインストールしている場合

`setup.bat` は、PostgreSQL が入っている PC では、データベースの作成をスキップします。
その場合は、**①環境構築** フォルダの **setup_db.bat** をダブルクリックして、データベース（myappdb）を作成してください。
postgres ユーザーのパスワードとポート番号を聞かれるので、入力します。

## ご注意

- **管理者権限のあるアカウント**でログインして実行してください。
- Windows のユーザー名に日本語（全角文字）が含まれていたり、フォルダのパスにスペースや特殊文字があったりすると、トラブルが発生しやすくなります。
- インストールした記録は、デスクトップの `setup_log.txt` に保存されます。
- すでにインストールされているソフトは、自動でスキップされます。

## 問題が発生した場合

環境構築で問題が発生しても、**講義の中で講師が対応します**。自分で解決できなくても、慌てずに、講義の時間に相談してください。
そのとき、画面の様子と、デスクトップの `setup_log.txt` を見せていただけると、原因を調べやすくなります。
