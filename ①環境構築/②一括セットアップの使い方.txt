■ 一括セットアップツールの使い方

このフォルダの setup.bat を実行すると、
 - [③ツール一覧.txt]の資材をすべてダウンロードし、[資材]フォルダに格納
 - [①手順.txt]の「１．資材をインストール」を自動実行
 - [①手順.txt]の「２．商品データベースを生成」を自動実行
 ※既にインストールされているツールは自動でスキップします。


【実行】
　1. setup.bat をダブルクリック
　2. 「このアプリがデバイスに変更を加えることを許可しますか?」→［はい］
　3. 黒い画面に進み具合が表示されるので、終わるまで待つ(10～20分程度)
　　　※途中で「Pleiades All in One 自己解凍書庫」の画面が出たら、展開先(c:\pleiades\…)は変えずに［解凍］を押す
　4. 最後に表示される「結果」を確認する
　　　インストール完了 …… 問題なし
　　　スキップ ………………… 既にインストール済み(何もしていない)
　　　失敗 ……………………… 手順.txt の手順で、そのツールだけ手動でインストールする
　5. 開いていたコマンドプロンプトや VS Code は一度閉じる(Path の変更を反映するため)

【自動で設定される内容】
　Eclipse    C:\pleiades\(バージョン) に展開、デスクトップにショートカット
　Python     全ユーザー版としてインストールし、Path に追加
　VS Code    全ユーザー版としてインストール、手順.txt の追加タスクをすべて ON、Python 拡張・日本語化も追加(拡張機能はログイン中のユーザーに追加)
　PostgreSQL postgres のパスワード 1234、ロケール C、bin フォルダを Path に追加
　psqlODBC   64 ビット版をインストール
　DB         ユーザー myapp(パスワード 1234)、データベース myappdb、テーブルとデータ

【注意】
　・管理者権限のあるユーザーでログインして実行してください。
　　別の管理者アカウントのパスワードを入力して実行すると、VS Code と Python が
　　そのアカウント側に入ってしまいます。
　・VS Code の拡張機能の追加にはインターネット接続が必要です。
　・PostgreSQL が既にインストールされている場合は、テーブル作成もスキップします。
　　下の【PostgreSQL が既にある場合】の手順でデータベースを作成してください。
　・Excel が 32 ビット版の場合は警告が出ます。psqlodbc_x86.msi を別途インストールしてください。
　・実行の記録はデスクトップの setup_log.txt に保存されます。

【PostgreSQL が既にある場合】
　1. このフォルダの setup_db.bat をダブルクリック →［はい］
　2. 「続けますか? (Y/N)」で Y を入力
　　　※既に myappdb がある場合、テーブルとデータは初期状態に戻ります
　3. postgres ユーザーのパスワードを入力(入力した文字は表示されません)
　4. ポート番号は、変更していなければそのまま Enter
　5. 結果に「テーブル作成：作成完了」と出れば完了
　うまくいかない場合は、商品関連テーブル作成\_テーブル生成.txt の手順で手動で作成してください。
