
ソフトのダウンロード(公式サイトから)

①A5M2(DB クライアント - インストール不要　解凍したファイルにあるA5M2.exeを起動するだけ)
	a5m2_2.21.1_x64.zip
	https://a5m2.mmatsubara.com/
	

②Pleiades All in One Eclipse(Java 開発環境) → Windows 64bit/Java 版を選びます
		パッケージに含まれているもの：Eclipse本体 + 日本語化プラグイン + Java 開発・実行環境（JDK / JRE）
	pleiades-2026-06-java-win-64bit-jre_20260705.exe
	https://willbrains.jp/

③Visual Studio Code
	VSCodeUserSetup-x64-1.144.0.exe
	https://code.visualstudio.com/download

④PostgreSQL	postgresql-18.6-5-windows-x64.exe
	https://www.postgresql.org/download/windows/

⑤psqlODBC(VBAマクロで使用 - 任意、VBAマクロを使用する場合にインストール)
	psqlodbc_x64.msi
	https://www.postgresql.org/ftp/odbc/releases/


※PostgreSQL JDBC ドライバ(postgresql-42.x.x.jar)は、Maven が自動で取り込むので、手動でダウンロードしません。
【注意】インストール先のパスに注意：Windowsのユーザー名に日本語（全角文字）が含まれている場合や、フォルダパスにスペース・特殊文字があるとトラブルが発生しやすい
